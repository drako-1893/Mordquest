Cómo jugar

Selecciona un personaje. Toca una casilla para anotar su inicial o mantenla pulsada para colocar la ficha.

Activa Marca X y mantén pulsado mientras arrastras para marcar o quitar varias X. En pantallas táctiles, desactiva Marca X para desplazar el plano.

Pulsa Borrar y elige una casilla para limpiarla. Mantén pulsado Borrar o usa Mayús + Intro sobre el botón para reiniciar todo el tablero. Deshacer recupera el estado anterior.

Con el mouse, arrastra antes de que termine la pulsación para anotar iniciales en varias casillas. También puedes mantener el botón derecho y arrastrar para marcar o quitar varias X. Un clic derecho alterna una X o retira una ficha. Con el teclado, usa Mayús + Intro en la casilla para colocarla.

«Al lado» significa una casilla arriba, abajo, a la izquierda o a la derecha, dentro de la misma zona. Norte y sur comparan filas. Este y oeste comparan columnas.

Coloca a los personajes en cualquier orden. Solo cabe una persona por fila y columna. El culpable es la única persona que comparte sala con la víctima.
