    Cómo jugar

    Selecciona un personaje. Toca una casilla para anotar su inicial o mantenla pulsada para colocar la ficha.

    Usa Marca X para poner o quitar una X. Usa Borrar para retirar una ficha, una inicial o una X. Mantén pulsado Borrar o usa Mayús + Intro sobre el botón para limpiar las anotaciones manuales.

    Con el mouse, el clic derecho alterna una X o retira una ficha. Con el teclado, usa Mayús + Intro en la casilla para colocarla.

    «Al lado» significa que las casillas comparten un borde. Norte y sur comparan filas. Este y oeste comparan columnas.

    Coloca a la víctima al final. El culpable es la única persona que comparte su sala.
